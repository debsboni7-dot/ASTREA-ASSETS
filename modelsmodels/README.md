ASTREA — Modèles 3D

Ce dossier contient les modèles 3D utilisés dans le jeu ASTREA.

Organisation

- characters : personnages masculins et ennemis.
- buildings : maisons et bâtiments.
- environment : arbres, rochers et éléments du monde.
- weapons : épées et autres armes.
- objects : objets du jeu.

Formats acceptés

- .glb
- .gltf

Règles

- Conserver les noms originaux des modèles.
- Vérifier les animations et les textures.
- Ne pas remplacer un modèle utilisé sans vérifier sa compatibilité.
