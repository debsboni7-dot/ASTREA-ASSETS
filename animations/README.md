ASTREA — Animations

Ce dossier contient les animations des personnages et des créatures du jeu ASTREA.

Animations prévues

- idle : personnage immobile.
- walk : marche.
- run : course.
- jump : saut.
- attack : attaque.
- dodge : esquive.
- death : animation de défaite.

Formats possibles

- .glb
- .gltf
- .fbx

Règles

- Vérifier que les animations correspondent au squelette du personnage.
- Tester chaque animation avant son intégration au jeu.
- Conserver les fichiers originaux.
